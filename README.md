# Phishing Email Detection System

A cybersecurity internship project (Qveto Technologies). It classifies an email as
`phishing` or `legitimate`, gives a risk score with a level (low / medium / high), and
lists the main reasons behind the score so an analyst can decide quickly. It reads
emails as **text only**: it never opens links, runs attachments or uses the network.

Built by a team of six over four weeks. A person always makes the final decision.

## What it does

- Loads a public labeled dataset described by a small config file
- Cleans records, removes duplicates and conflicting labels, audits quality
- Splits data into train / validation / test without leakage (the test set is used once, at the end)
- Builds hand-made features (sender, URL, text) and word features (TF-IDF)
- Trains and compares four models, saves the best with its metadata
- Scores new emails (pasted text, `.eml` or `.csv` upload) with explanations and attachment warnings
- Stores a privacy-safe history and exports Markdown / JSON / CSV reports
- Offers a REST API (FastAPI) and a web interface (Streamlit)

## Quick start

```
python -m venv .venv
.venv\Scripts\activate          # Windows (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
python -m pytest
```

Full instructions: `docs/setup-guide.md`. In short:

```
python scripts/make_splits.py
python scripts/train.py
python scripts/evaluate.py                    # once, on the test split
uvicorn app.api:app --reload                  # API docs at /docs
streamlit run app/streamlit_app.py
```

The dataset is not included. Follow `docs/dataset-selection.md` and keep raw data out of git.

## Results

All numbers are generated by scripts and stored in `reports/`:

| Report | Produced by |
|---|---|
| `reports/dataset_audit.md` | `scripts/audit_dataset.py` |
| `reports/split_summary.md` | `scripts/make_splits.py` |
| `reports/baseline_metrics.md` | `scripts/run_baseline.py` |
| `reports/model_comparison.md` | `scripts/train.py` (validation split) |
| `reports/final_evaluation.md` | `scripts/evaluate.py` (test split) |
| `reports/test_log.txt` | `python -m pytest -v` |

How to read them: `docs/interpreting-results.md`. Weaknesses and error examples: `docs/limitations.md`.

## Limits

This is an internship prototype trained on one public dataset. It does not read email
headers, check SPF/DKIM/DMARC, inspect attachment contents or render HTML. A low score
is not a guarantee of safety. See `docs/limitations.md`.
