# Feature reference

Generated by `scripts/make_feature_reference.py` from the registered features. Do not edit by hand;
change the feature's description in `src/features/` and run the script again.

There are 33 hand-built features. Every feature is one number per email. Links are only read as text.

## Sender features (11)

| Feature | What it measures |
|---|---|
| `sender_has_sender` | The email has a sender value. |
| `sender_has_domain` | The sender looks like an email address with a domain. |
| `sender_free_mail` | The sender uses a free webmail provider. |
| `sender_display_name_mismatch` | The display name contains a web address or email address that differs from the real sender domain. |
| `sender_local_digit_count` | Number of digits in the part of the address before the @ sign. |
| `sender_domain_length` | Length of the sender domain; very long domains are often auto-generated. |
| `sender_subdomain_count` | Number of subdomain levels in the sender domain (mail.shop.example.com has 2). |
| `sender_hyphen_count` | Number of hyphens in the sender domain. |
| `sender_suspicious_tld` | The sender domain ends in a top-level domain often used in abuse. |
| `sender_ip_domain` | The sender 'domain' is a raw IP address. |
| `sender_punycode` | The sender domain uses punycode (xn--), which can disguise look-alike characters. |

## URL features (11)

| Feature | What it measures |
|---|---|
| `url_count` | Number of web addresses in the email. |
| `url_unique_domains` | Number of different domains linked in the email. |
| `url_ip_host` | A link points to a raw IP address instead of a domain name. |
| `url_has_at_symbol` | A link contains an @ sign before the host, which can hide the real destination. |
| `url_shortener` | A link uses a URL-shortening service that hides its destination. |
| `url_max_length` | Length of the longest web address (long addresses can hide the real domain). |
| `url_max_subdomains` | Largest number of subdomain levels in any linked domain. |
| `url_max_hyphens` | Largest number of hyphens in any linked domain. |
| `url_punycode` | A link uses punycode (xn--), which can disguise look-alike characters. |
| `url_plain_http` | A link uses unencrypted http instead of https. |
| `url_anchor_mismatch` | A link's visible text shows one domain but the link actually goes to a different domain. |

## Text features (11)

| Feature | What it measures |
|---|---|
| `text_subject_length` | Number of characters in the subject. |
| `text_body_words` | Number of words in the body. |
| `text_exclamations` | Number of exclamation marks, often used to create pressure. |
| `text_uppercase_ratio` | Share of letters that are capitals (shouting). |
| `text_urgent_words` | Number of urgent or threatening phrases such as 'act now' or 'suspended'. |
| `text_credential_words` | Number of words asking for logins, passwords or account verification. |
| `text_money_words` | Number of words about prizes, payments or money transfers. |
| `text_has_html` | The body contains HTML markup. |
| `text_has_form` | The body contains an HTML form, which can be used to collect passwords. |
| `text_fake_reply_prefix` | The subject starts with 'Re:' or 'Fwd:', which can fake an earlier conversation. |
| `text_digit_ratio` | Share of characters that are digits. |
